二、员工人事政策

──────────────────────────────

1. 工作时间  

   - 标准工时：周一至周五，9:00–18:00，午休12:00–13:00  

   - 弹性工作制：核心工作时段10:00–16:00必须在线，其余时间可灵活安排  

   - 远程办公：每月最多8天，需提前3个工作日通过OA系统申请，直属经理审批  


2. 假期制度  

   - 法定年假：  

     • 司龄1–3年：10天/年  

     • 司龄3–10年：15天/年  

     • 司龄10年以上：20天/年  

   - 病假：每年5天带薪病假，需提供二级以上医院证明  

   - 婚假：15天（凭结婚证）  

   - 产假：158天（含国家规定98天+地方奖励60天）  


3. 薪酬与福利  

   - 发薪日：每月10日（遇节假日顺延）  

   - 五险一金：全额缴纳，公积金比例12%（公司+个人各12%）  

   - 年度体检：每年9月统一安排，覆盖基础套餐+专项筛查（35岁以上）  

   - 节日福利：春节、中秋发放800元购物卡；端午、元旦发放300元

四、技术架构概要（供研发参考）

──────────────────────────────

- 后端语言：Python 3.10 + FastAPI  

- 数据库：PostgreSQL 14（主从集群）、Redis 7（缓存）  

- 向量数据库：ChromaDB v0.4.22（部署于10.20.30.100:8000）  

- 消息队列：RabbitMQ 3.12  

- 部署方式：Docker Compose + Nginx 反向代理  

- 日志收集：ELK Stack（Elasticsearch + Logstash + Kibana）  


关键服务端口：

- Web API：8002  

- ChromaDB：8000  

- PostgreSQL：5432  

- Redis：6379

五、客户服务流程

──────────────────────────────

1. 客户问题分级  

   - P0（紧急）：系统宕机、数据丢失 → 30分钟响应，2小时恢复  

   - P1（高）：核心功能不可用 → 2小时响应，24小时内修复  

   - P2（中）：非核心功能异常 → 1个工作日内响应  

   - P3（低）：UI优化、文案建议 → 纳入需求池  


2. SLA承诺  

   - 系统可用性 ≥ 99.9%（全年宕机不超过8.76小时）  

   - API平均响应时间 < 500ms（P95）
